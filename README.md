## 📻 Background & Heritage

AuthorPlay is the direct predecessor to [rsnra.link](https://rsnra.link) — much of its philosophy, core concepts, and DNA were carried forward into the modern RSNRA ecosystem.

- **The 2017 Origins**: The project was originally conceived and built back in 2017 on PHP. Unfortunately, that original codebase was lost forever when the hard drive containing it died.
- **Rewritten from Scratch**: Because this project holds significant personal meaning as a major milestone, I decided to rewrite it completely from scratch just for fun.
- **The Modern State**: Before `rsnra.link` emerged, I initially rewrote the backend in PHP 8. However, once `rsnra.link` went live, that backend became legacy and is no longer used.
- **Connected to rsnra.link**: Today, AuthorPlay is configured to pull its live media library directly from **rsnra.link**. This keeps this beloved legacy project fully alive, functional, and testable in production.

🌐 **Live Demo**: [https://authorplay.bottocloud.com/](https://authorplay.bottocloud.com/)

## 🌟 Features

- **Direct Music Streaming**: Clean, minimalist web player focused on discovering independent artists.
- **rsnra.link Integration**: Seamlessly streams music from the modern RSNRA media catalog.
- **Inclusive Platform**: Created with indie creators and music discovery in mind.
- **Streaming Made Simple**: Fast, lightweight interface built with React 18, Vite, and TypeScript.
